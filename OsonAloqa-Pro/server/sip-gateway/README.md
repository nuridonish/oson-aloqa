# 📞 SIP-Gateway — занг аз барнома ба рақами оддии телефон

## Чӣ тавр кор мекунад

```
Приложение (SIP) → Ваш Asterisk-сервер → Оператор-шлюз (Twilio/Telnyx/местный) → Обычный номер
```

Занг тавассути **интернет** то шлюз меравад — аз ҳар ҷои ҷаҳон бо нархи шлюз, на роуминги оператор.

## Қадам 1 — Сервер (VPS, Ubuntu)

```bash
apt install asterisk        # ё docker compose up -d (папкаи sip-gateway)
nano /etc/asterisk/pjsip.conf   # аз conf/pjsip.conf нусхабардорӣ + ПАРОЛ ва Twilio
systemctl restart asterisk
```

Портҳои кушод: UDP 5060 + UDP 10000-10100 (RTP).

## Қадам 2 — Trunk (пул ба шабакаи телефонӣ)

Вариантҳо:
- **Twilio / Telnyx** (ҷаҳонӣ, картаи бонкӣ) — SIP trunk бо ҳисоб-китобӣ ба дақиқа
- **Шабакаи маҳаллӣ** (Тоҷикистон/Русия) — ҳар операторе, ки SIP-trunk медиҳад

Дар `pjsip.conf` ҷойгузорӣ кунед: `TWILIO_SIP_USER/PASS` ва ҳоcт.

## Қадам 3 — Дар барнома

Профил → **SIP-шлюз** → ворид кунед:
- Сервер: `IP-и-VPS:5060`
- Номи корбар: `oson-app`
- Рамз: ҳамон, ки дар pjsip.conf

Баъд дар чат ҳангоми занг: **«Занги SIP (интернет-шлюз)»** ё «Занги SIM» — интихоб мекунед.

## Нархҳо (масалан)
| Самт | Twilio (тақрибан) |
|---|---|
| Русия → Тоҷикистон | ~$0.15/дақ |
| Тоҷикистон → Русия | ~$0.10/дақ |
| Дохилӣ (аз сервер) | ~$0.01–0.03/дақ |

Ин нархро **шлюз** муқаррар мекунад — барнома танҳо ройгон пайваст мешавад.

- SipManager-и Android дар баъзе дастгоҳҳо маҳдуд аст — санҷед (боқимонда: Linphone-SDK)
