# Осон Алоқа — месинҷери офлайн (SMS + занги SIM)

«Осон Алоқа» — барномаи мессенҷер, ки **бе интернет** кор мекунад:

- **Паёмҳо** ҳамчун SMS-и муқаррарӣ фиристода мешаванд — аз **ҳисоби симкарта**, на мегабайт.
- **Зангҳо** аз ҳисоби симкарта (GSM) — тугмаи занг дар чат.
- **Регистратсия** бо рақамҳои **ҳамаи кишварҳои ҷаҳон** (формат +992, +7, +1 ...), офлайн, бе сервер.
- **4 забон**: Тоҷикӣ, Русӣ, Инглизӣ, Ӯбекӣ (Меню → Забонро интихоб кунед).
- Логотип: «ОСОН / АЛОҚА» (файли `logo.png`).

## Хусусиятҳои муҳим

| Имконият | Чӣ тавр кор мекунад |
|---|---|
| Паём фиристодан | `SmsManager` — SMS-и муқаррарӣ, пул аз баланcи SIM |
| Паём гирифтан | `BroadcastReceiver` (SMS_RECEIVED) — офлайн |
| Занг | Тугмаи ☎ дар чат → занги муқаррарии GSM |
| Видео-занг бе интернет | ИМКОНАПАЗИР аст — операторон ва Apple/Google API-и 3G-видеоро бастаанд |
| Офлайн | Ҳама чиз: паёмҳо, базаи маълумот, регистратсия — интернет лозим нест |

## Чӣ тавр APK созем (қадам ба қадам)

1. **Android Studio**-ро аз https://developer.android.com/studio насб кунед (интернет танҳо барои насб лозим аст; барномаи тайёр офлайн кор мекунад).
2. Android Studio-ро кушоед → **Open** → папкаи `OsonAloqa`-ро интихоб кунед.
3. Интизор шавед, ки Gradle sync тамом шавад (бори аввал интернет мехоҳад — китобхонаҳоро мегирад).
4. Меню: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. APK тайёр мешавад дар:
   `OsonAloqa/app/build/outputs/apk/debug/app-debug.apk`
6. Файли APK-ро ба телефон гузаронед ва насб кунед (нигоҳубин → насби барномаҳои номаълум → иҷозат).

### Барои нашри расмӣ (Play Market / дигарон)
`Build → Generate Signed App Bundle / APK → APK` — keystore эҷод кунед ва вориди имзо намоед.

## Иҷозатҳое, ки барнома мепурсад

- **SMS** (фиристодан/қабул/хондан) — барои паём аз ҳисоби симкарта
- **Телефон** — барои занг
- **Контактҳо** — барои интихоби рақам аз дафтарча (ихтиёрӣ)
- **Огоҳиномаҳо** — барои огоҳии паёми нав (Android 13+)

> Ҳамаи паёмҳое, ки мегиред, дар барнома нигоҳ дошта мешаванд. Агар бихоҳед, ки SMS-ҳо ТАНҲО дар «Осон Алоқа» нишон дода шаванд: Танзимот → Барномаҳо → Барномаҳои пешфрз → SMS → «Осон Алоқа»-ро интихоб кунед (агар рӯйхат нишон диҳад).

## Санҷиши сифати паём (статус)
⏳ фиристода истодааст • ✓ расид • ✓✓ супориш шуд • ✗ фиристода нашуд (сим ё баланс санҷед)

## Айфон (iOS)
Папкаи `OsonAloqa-iOS` — лоиҳаи SwiftUI. Мӯҳлати муҳим: Apple ба барнома иҷоза намедиҳад SMS-ро паспардонон бинию фиристад. Дар iPhone:
- Фиристодан — тавассути тирезаи аслии SMS бо тасдиқи корбар (аз ҳисоби симкарта);
- Қабул — дар барномаи аслии Messages;
- Занг — тавассути симкарта.
Тафсилот: `OsonAloqa-iOS/README.md`

# Версия 3.0 — «OsonAloqa-Internet» (зангҳои интернетӣ мисли WhatsApp)

Папкаи лоиҳа: `OsonAloqa-Internet` • Файл: `OsonAloqa-Internet.apk` (Android 5.0+)

## Галучкаи «Интернет» дар чат:
- **ОФ** = занг ба рақам — аз тарифи симкарта
- **ОН** = занг тавассути интернет (WebRTC) барнома → барнома, овоз ё видео 📹
- Агар он тараф ҷавоб надод → пешниҳоди занги SIM

## Шартҳо:
1. Ҳарду тараф `OsonAloqa-Internet.apk` дошта бошанд (Android 5.0+)
2. Ҳарду тараф онлайн бошанд
3. Пайваствшавӣ тавассути сервери умумӣ (broker.emqx.io) — бе харҷи хостинг
4. Занги воридшуда ҳангоми кори барнома меояд (push-хадамот — марҳилаи оянда)

## Санҷиш:
Дар Android 4.4 насб намешавад (minSdk 21). Барои телефонҳои куҳна `OsonAloqa.apk` (v2) истифода баред.
